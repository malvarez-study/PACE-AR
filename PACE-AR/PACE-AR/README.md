# PACE AR Website

Complete React + Vite website source, assets, and the latest production build.

## Run locally
1. Install Node.js 22.12 or newer.
2. Extract this ZIP and open the PACE-AR folder in VS Code.
3. Open a terminal in that folder.
4. Run: npm install
5. Run: npm run dev
6. Open the localhost address printed in the terminal.

## Build for hosting
Run npm run build. Upload the contents of dist/ to a static hosting service.
To check the production build locally, run npm run preview.
Use a web server for dist/ rather than double-clicking index.html.

## Contents
- src/: React components, interactions, animations, responsive styles
- public/: watch images, photos, logos, icons, and other assets
- dist/: latest ready-to-host production build
- package.json, pnpm-lock.yaml, vite.config.ts, tsconfig.json: project configuration

The checkout is a demonstration interface and does not process real payments or submit real orders.
